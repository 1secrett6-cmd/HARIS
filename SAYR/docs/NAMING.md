# اختيار الاسم

## الاسم المختار: سَيْر — SAYR

- **المعنى:** "حركة السَّير" هي الكلمة اللي بيستخدمها كل أردني للمرور (شرطة السير، أزمة سير). الاسم محلي 100% ومفهوم فورًا.
- **عالميًا:** قصير (4 أحرف)، سهل اللفظ بالإنجليزي، ويصلح كعلامة تجارية وتطبيق ونطاق.
- **الشعار:** *See. Predict. Act.* — نرى. نتنبّأ. نتصرّف.
- **الوصف:** The AI Traffic Command Brain — العقل المروري الذكي.
